# Privacy Policy — SportMax

Last updated: November 23, 2026

SportMax is a private, single-user health
analytics integration.

## Data collected
With the owner's authorization, SportMax retrieves
Oura sleep, readiness, HRV, heart rate, stress,
activity and other permitted health metrics.

## Data processing
Data is processed on the owner's self-hosted server.

Selected data may be shared with OpenAI ChatGPT
when the owner requests analysis or enables
scheduled reports.

## Storage and security
Authentication credentials are stored privately
on the owner's server.

No personal health data or API credentials
are published in this GitHub repository.

## Data sharing
Health data is not sold or used for advertising.

## Revocation and deletion
The owner may revoke Oura authorization
and delete locally stored data and credentials.
