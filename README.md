# SportMax — Oura Integration

SportMax is a private, self-hosted personal health
and cycling analytics integration.

Data sources:
- Oura Ring: sleep, HRV, readiness and recovery
- Garmin Connect: activities and training metrics
- FatSecret: nutrition

Oura data is accessed with the account owner's
authorization via OAuth 2.0.

Data may be processed by ChatGPT for personal
analysis and training recommendations.

This repository contains public documentation only.
It contains no health records, tokens or source code.

SportMax is independent of Oura, Garmin and FatSecret.
